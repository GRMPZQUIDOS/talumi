# Contributing to Talumi

Talumi is built with translators first. You do not need to write code to help.

## 1. Contribute a difficult case (no code)

A difficult case is the most valuable contribution today. Open an issue titled **"Case: <short name>"** with:

- **Source**: the original passage and its language.
- **Wrong translation**: a plausible translation that changes the meaning.
- **Consequence**: what could go wrong if someone relied on it.
- **Right solution**: the correct translation and why.
- **Source of the case**: real (with a public reference) or constructed.

Do not post confidential client material. Use public texts or rewrite the passage.

Cases used to improve Talumi are kept separate from cases used to evaluate it, so that progress is measured honestly.

## 2. Contribute code

The engine will be published when the first checking path is implemented. Until then, discussion of the method and architecture is welcome in issues.

When code contributions open:

- Keep changes small and explained.
- Every check must be traceable: a model call that did not run must never be reported as run.
- Never commit API keys, client documents or personal data.

## 3. Contributor agreement

Before a code contribution can be merged, you will be asked to accept the Talumi Contributor License Agreement ([CLA.md](CLA.md)). You keep the copyright of your work. The agreement lets the project maintain and, if needed, relicense the code as a whole.

## 4. Conduct

Be precise, be kind, cite your sources.
