# Roadmap

## Now: beta in preparation

- [x] Method and principles published ([docs/method.md](docs/method.md))
- [x] Public cases documented ([docs/cases.md](docs/cases.md))
- [x] License, trademark policy, contribution rules
- [x] Website and beta sign-up for translators and clients

## Next: first checking path

- [ ] One language pair, a small number of independent paths, really executed and logged
- [ ] Comparison of meaning between paths: who, what, conditions, exceptions, negations, numbers
- [ ] Report for the translator: passages at risk, passages to validate
- [ ] Trace of every model call (provider, model, time, inputs and outputs or their hashes)
- [ ] **Engine code published in this repository**
- [ ] **Service online**

## Then

- [ ] Credit account for translators, price per document
- [ ] Client report showing only the translator's own price
- [ ] Registry of verified translators and verifiable certificates
- [ ] Plugins for translation tools (OmegaT first)
- [ ] Library of difficult cases contributed by translators
- [ ] Independent evaluation: professional alone, AI alone, professional with Talumi
